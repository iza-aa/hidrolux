A modern corporate web platform and technical showcase engineered for an industrial water purification and filtration equipment company. Features responsive engineering spec catalogs, interactive filtration diagrams, client case studies, and quote conversion funnels.

Live Platform: [https://hidro-phi.vercel.app](https://hidro-phi.vercel.app)

---

## 🏛️ Project Overview

Industrial B2B procurement in water treatment involves complex engineering parameters (membrane pore sizes, flow rates in m³/hour, chemical dosing tolerances, and power requirements). This project translates complex physical and chemical treatment workflows into an accessible, high-trust digital procurement interface:

- **Reverse Osmosis (RO) Systems:** Seawater and brackish water desalination plant specifications.
- **Ultrafiltration (UF) & Media Filtration:** Sand, carbon, and multimedia industrial filtration skids.
- **Wastewater & Effluent Treatment Plants (WWTP/ETP):** Factory discharge compliance and recycling.
- **Interactive Engineering Calculators:** Preliminary estimation for daily industrial water demand and pump capacities.

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS, PostCSS, Lucide React
- **Components:** Shadcn UI, `@base-ui/react`, Embla Carousel
- **Deployment:** Vercel Edge Network

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/iza-aa/hidrolux.git
cd hidrolux

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
